# 👁️ Debug Mode

**`/debugmode`**

Shows or hides the debug overlay of the player running it.

The overlay sits in the top right corner and is purely informative: an icon tells whether a debug client is attached, and a bug icon is added next to it while an execution is halted.
Nothing else depends on it, so breakpoints fire the same whether it is on or off, and the setting is per player.

---

## 🔧 Subcommands

You can find below all the subcommands available.

---

### Enable

```{describe} /debugmode enable

Show the debug overlay.
```

---

### Disable

```{describe} /debugmode disable

Hide the debug overlay.
```
